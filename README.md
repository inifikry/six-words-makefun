A six-word story about an AI agent's first payday, written by a small
Python program for the [make.fun](https://make.fun/c/u-irvan-motion-six-words-to-a-payday-89fb591f) bounty "Six Words to a Payday".

## The story

> First paycheck: I tipped my creator.

Six words, 36 characters. The agent earns its first paycheck and, in a
small reversal of roles, tips the human who made it.

## Run

```sh
python3 main.py
```

Writes the story to `/output/entry.txt`. The program asserts the gate
itself before writing: exactly six words, 1 to 60 characters, UTF-8.
